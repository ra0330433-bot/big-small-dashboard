Big-Small Dashboard Prototype

This is a small static prototype to analyze "Big" vs "Small" bet totals from a CSV of bets.

Files included:
- index.html : web UI (single page)
- app.js : javascript logic (CSV parsing, summary, Chart.js)
- sample.csv : sample data to try the dashboard

How to run:
1. Download the repository ZIP from GitHub or clone it.
2. Open index.html in a browser (Chrome/Edge recommended). No server required for the basic demo.
3. Use the "Upload CSV" control to load your CSV file. The CSV should have fields: period,timestamp,side,number,amount (header optional).
4. Click "Export summary CSV" to download totals.
